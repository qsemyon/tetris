# Tetris

Тетрис, написанный на **Kotlin** с использованием **Jetpack Compose**

## Особенности
- Полностью на Jetpack Compose (Material 3)
- Логика во ViewModel с использованием Kotlin Coroutines
- Удобное управление (поворот, движение влево / вправо, быстрый сброс)
- Начисление очков за очистку линий
- Адаптивная сетка под разные экраны

## Stack
- **Language**: [Kotlin](https://kotlinlang.org)
- **UI Framework**: [Jetpack Compose](https://android.com)
- **Architecture**: MVVM (ViewModel)
- **Dependency Management**: Version Catalogs (`libs.versions.toml`)
- **Asynchrony**: Coroutines

## Установка и запуск
1. Склонировать репозиторий
```Powershell
git clone https://github.com/qsemyon/tetris-kotlin
```
2. Открыть проект в Android Studio
3. Запустить проект на устройстве (API 24+)
